The earlier SOL fee paid when buying SPARKD does not prepay later Solana transactions. The sponsor needs its own SOL reserve for each sponsored swap. This preview makes that project cost visible in the economics tab.

SPARKD is the app's service fee and is transferred to the app in the swap transaction. The sponsor separately pays network SOL; SPARKD does not need to be the sponsor's fee token.

Build demand before building a chain

Use explicit gates so the larger network step follows evidence of use.

GATE 1 · USEFUL PRODUCT

Make the first swap easy

Start with a few liquid, commonly requested pairs; show the best available route, final output, slippage, route cost, and SPARKD fee before approval.

GATE 2 · REPEAT USE

Measure cohort return

Track completed swaps, unique wallets, 7/30-day repeat use, quote-to-completion rate, failures, support issues, SPARKD fees collected, and sponsor SOL consumed.

GATE 3 · SUSTAINABLE COSTS

Show positive unit economics

After operating costs and a reserve for fee-sponsor SOL, show positive contribution for several consecutive months and a plan to replenish the sponsor wallet.

GATE 4 · NETWORK READINESS

Only then evaluate a SPARKD chain

Require demonstrated demand, independent security review, validator commitments, reliable wallets/RPC/explorer, liquidity, and a safe migration plan.

TEST ROUTE

Raydium documents partial Devnet deployments and fetching CPMM pool state through RPC. Devnet liquidity is sparse, so the selected pool ID must be verified before a test.

TEST FEE TOKEN

A disposable SPARKD-like mint

The production SPARKD mint lives on Solana mainnet. Devnet needs a separate test mint to exercise the app's SPARKD fee transfer. The sponsor must permit the transaction programs; it does not need to accept SPARKD as its own payment token.

A mainnet swap quote cannot be paired with a Devnet sponsor. Both the route and sponsor must use the same cluster.

Suggested rollout

Keep the first milestone narrow and measurable
01 · DEVNET

Prove the fee flow

Compose a swap and SPARKD payment; have a sponsor pay network SOL. Verify the user is never asked for SOL as gas.

02 · LIMITED MAINNET PILOT

Invite a small group

Set a low, disclosed fee. Cap each sponsor transaction, daily spend, and total SOL reserve. Monitor every quote, signature, and settlement.

03 · EXPAND ON EVIDENCE

Grow use, then assess chain

Keep funding the sponsor from collected fees and project treasury. Expand pairs and access as reliability and repeat usage are proven.
