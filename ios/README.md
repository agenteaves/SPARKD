# SPARKD iPhone Home Screen app

This directory provides an installable iPhone web app entry point. On iPhone, open `/ios/` in Safari and use Share → Add to Home Screen. The Home Screen app links to the existing mobile Meme Forge and contest submission pages, which share the same production backend. It does not contain or modify Android code or publish an iOS App Store binary.

The contest flow still depends on the mobile browser and a compatible Solana wallet for transaction signing. Validate wallet handoff, PNG export, upload, and submission on an actual iPhone before describing the entire flow as tested.
