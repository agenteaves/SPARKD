# SPARKD Daily Arcade

An independently developed browser-game project for the SPARKD community.

## Initial game: SPARKD Runner

A mobile-first superhero runner featuring the established SPARKD hero (blond hair, green mask, black-and-green suit, gold accents, green cape). Players dodge obstacles, collect energy, and earn points.

## Isolation

This directory is a standalone work area. Do not link it from or modify the production SPARKD website until the game has been tested and explicitly approved.

## Planned milestones

1. Build a playable responsive runner with keyboard and touch controls.
2. Add game-over, scoring, and restart flows.
3. Add authenticated accounts, server-validated scores, and daily play limits.
4. Add a leaderboard and weekly competitions.
5. Test on mobile and desktop, review abuse protections and reward rules.
6. Integrate into the main site only after approval.

## Assets

Use the original SPARKD superhero assets from the existing site when available; the supplied screenshot is a visual reference, not a production-ready transparent sprite.
