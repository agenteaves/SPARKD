# SPARKD traffic exchange splash

Standalone static Cloudflare Pages site. Publish this directory (`traffic-splash`) from branch `feature/traffic-splash` in a **separate Cloudflare Pages project**. Framework preset: None. No build command. Output directory: `.`. The existing GitHub Pages site is unchanged.

Use each exchange's unique URL such as `https://YOUR-PROJECT.pages.dev/?source=easyhits4u`. The only effect of `source` is a validated `utm_source` on the two outbound buttons; it cannot change the destination. Both buttons lead to the official site. The page makes no auto-redirect and does not request wallet access.
